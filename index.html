Grammar & Language Specification

Non-eval() AST Parser
AVERAGE(m1, m2, ...)

Accepts 1 or more valid marks (0–100). Returns the calculated arithmetic mean.

Example: AVERAGE(80, 70, 90) → 80
PASS(mark)

Accepts exactly 1 mark (0–100). Returns TRUE if mark ≥ 50, else FALSE.

Example: PASS(65) → TRUE
ELIGIBLE(mark, flag)

Accepts 1 mark (0–100) and 1 boolean attendance flag (TRUE / FALSE). Returns TRUE if mark ≥ 45 AND flag is TRUE.

Example: ELIGIBLE(45, TRUE) → TRUE
